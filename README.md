# 花境洞察（zorr-insight）

zorr.pro 网页游戏的辅助工具：内嵌浏览器、神经网络训练可视化、敌方单位解析。

纯本地运行，不上传数据；除 AI 接口调用外不访问外网。

---

## 构建

```sh
sh build.sh
```

环境要求：JDK 17、Gradle 8.9、Android SDK 34、aapt2 补丁（容器内已就位）。

**签名密钥**：`app-source/app/keystore.p12` 含私钥，已排除在版本库外。
新克隆后需要自行放入该文件，或改用 debug 签名。

**注意**：本容器里 Gradle 增量编译会失效——改完源码后打包任务显示
`UP-TO-DATE`、APK 时间戳不变。`build.sh` 每次先清缓存规避。验证产物时
务必看时间戳或反查 dex 内容，不要只看 BUILD SUCCESSFUL。

## 功能

**主界面**：纯白底，顶栏按钮，中央游戏区；底栏可上滑展开训练面板。

**数据采集**：只读。用 `evaluateJavascript` 读取页面已渲染的 DOM 文本
（聊天、槽位、进度、昵称），以及 `PixelCopy` 抓取画面像素。
不修改页面状态，不发送输入事件。

**神经网络**：三路自监督训练，标签来自画面自身线索，无需人工标注。
- 区域：小地图下方区域名 → Garden/Desert/Ocean/Jungle/Hel
- 地图：整幅画面 6×6 网格颜色特征（292 维）
- 单位：血条亮度、色相、填充率

训练集与验证集按 4:1 分开，准确率是验证集上的真实值。样本无变化时不重复训练。

**敌方单位检测**：按血条定位。判据在实机截图上逐像素标定，见
`data/detector-baseline.json`。关键一条是「血条周围必须是纯地面」——
世界里的血条贴着地面，而 UI 元素周围是深色底或白边框。这一条把精确率
从 9% 提到 100%（单张截图 2 个目标 + 合成图 10 个目标对 16 个干扰项）。

**视觉识别**：把画面交给支持图像输入的模型，读出单位名、稀有度、血量。
识别结果按稀有度上色框在画面上，右侧按稀有度从高到低列表。
**仅读画面上的文字，不触碰游戏内部数据。**

**背包**：按 DOM 给出的槽位坐标从画面上裁出花瓣图标；名称需悬停一次后记住。

## 边界说明

这个项目**只做只读辅助**，以下事情不做：

- 不逆向游戏的混淆 JS、不 hook WebSocket 或渲染函数、不读闭包内实体表
- 不向游戏发送任何输入事件（不自动打怪、不自动按键）
- 不解析游戏的分享码（私有二进制格式，含密钥与字节变换）

理由：zorr.pro 是在线多人游戏，站点条款禁止反向工程。上述做法会越界。
游戏的画面、文字、DOM 文本都可以正常读取。

## 已知限制

- 花瓣名称无法从 DOM 直接读取（图标画在 canvas 上），需悬停一次积累映射
- 区域识别依赖小地图位置，界面改版后需重新标定
- 视觉识别的准确率取决于所配模型和画面清晰度，无法离线验证
- 检测判据在单张实机截图 + 合成图上验证过，未见过的场景（密集战斗、
  血条被遮挡）可能漏检

## 数据来源

掉落数据与中文名抓自官方 wiki（`zorrpro.fandom.com`）与游戏语言包
（`zorr.pro/lang/chinese.json`）。抓取脚本在 `data/`，可重新运行更新。
